- Docker：本机已用 Homebrew 装了 docker 命令行和 Colima（2026-11-16 检查时 Colima 未启动），用 `colima start` 启动即可，不需要 Docker Desktop，也不需要单独安装 PostgreSQL。学会最基本的启动、停止、查看日志。
- 新建 `jobpilot/`（独立 pyproject）、`web/`、`evals/` 目录；Docker Compose 启动 PostgreSQL + pgvector；SQLAlchemy + Alembic 初始迁移（含用户表）；基础 FastAPI 应用和测试数据库配置。架构决定见 [02 第 9 节](./02-技术架构与数据模型.md#9-已确认的架构决定2026-11-16)。
- 已定事项见 [00 第 6 节](./00-总览与决策.md#6-待用户确认的问题)：前端 React，模型暂定 DeepSeek，V1 个人本地使用、不上线。
- React 复习控制在 2～3 天，可与第 1 周后端开发穿插：组件与 props、`useState` / `useEffect`、调用接口、路由；其余边做边查。
- 开始收集 JD（目标 50 份），编写第一批合成简历（10 份）。

**完成标准：** 空应用能启动、测试能跑；收集到至少 20 份 JD。

**完成标准：** 用命令行或简单页面，能从一份简历得到事实清单，从一份 JD 得到要求清单；E2 有第一版 F1。

## 3. 找用户

**2026-11-16 起暂不考虑其他用户**，本节与第 4 节保留为以后开放时的参考。届时先用前两个渠道做邀请制内测，再考虑公开渠道。

| 渠道 | 做法 |
| --- | --- |
| 身边同学 | 第一批内测，当面观察怎么使用 |
| 熟人群（班级群、好友） | 简短介绍和邀请码，说明是个人项目、免费、测试阶段 |
| 牛客 | 发帖分享「我做了一个改简历不编造的工具」，附评测数据 |
| 小红书、即刻 | 用前后对比图展示效果（使用合成简历，不展示真实用户数据） |
| 技术社区（掘金、知乎） | 写技术文章，文末附项目链接 |

**原则：** 免费；不夸大效果；收集反馈的方式简单（页面上的点赞、点踩加一句话评论）；遵守各平台的推广规则。

## 5. 风险与应对

| 风险 | 信号 | 应对 |
| --- | --- | --- |
| 范围扩大、迟迟做不出可用版本 | 第 2 周结束时完整流程还跑不通 | 严格执行[设计冻结规则](./README.md#设计冻结规则)；砍掉 P1，先做出可用版本 |
| 再次陷入长时间调研 | 一周内写了多份选型文档，代码没有进展 | 用指定的库直接实现，有问题再换 |
| 依据检查误拦太多，改写变得没意义 | 回退率很高，用户接受率低 | 看 E4 的误拦案例，调整同义词表与等级规则；第三层改为只提示不拦截 |
| 模型成本超出预期 | 每次运行成本高于预算 | 用更便宜的模型做检查和解析；缓存匹配报告；限制每日次数 |
| 本人使用不够多，发现不了问题 | 第 4 周累计使用不到 10 次 | 把每次投递都用它处理一遍；结合 E5、E6 评测找问题 |
| 以后开放时的隐私事故 | 任何数据泄露迹象 | 开放前完成第 4 节检查清单；出现问题立即下线并通知用户 |
| 时间被项目占满 | 八股和刷题没有进展 | 每周检查时间分配；项目可以延期，求职准备不能停 |
