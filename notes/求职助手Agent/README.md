# 实习求职助手 Agent：设计文档入口

日期：2026-11-16（Asia/Taipei）。状态：**设计完成，已冻结（2026-11-16），尚未实施**。文中的范围、限额和周期是设计起点，没有实测数据支持；所有效果结论以后续代码、运行记录和评测为准。

## 一句话

帮正在找技术类实习的学生，把「看 JD → 对照简历 → 按岗位改简历 → 准备面试 → 跟踪投递」做成一条可追溯的 Agent 流程。核心约束是：**改写简历时不编造经历**，每一条输出都能回溯到用户确认过的原始材料。

## 分阶段总览

| 阶段 | 目标 | 主要功能 |
| --- | --- | --- |
| V1 个人可用版 | 自己能在本地用它处理真实 JD，有第一组评测数据 | 经历事实库、JD 解析、简历匹配、定制改写与依据检查、导出 |
| V2 面试版 | 覆盖面试准备，加入记忆与检索 | 模拟面试、面经知识库（RAG）、长期记忆、投递追踪与复盘 |
| V3 扩展版 | 补齐对照实验和对外接口 | 多 Agent 对照、MCP 服务、提示注入专项评测 |

## 设计冻结规则

本项目最大的风险是范围不断扩大、迟迟不写代码。因此约定：

1. V1 范围以本套文档为准。实施中想到的新功能，先记入 [05 落地与里程碑](./05-落地与里程碑.md#6-v2-及以后的待办池)的待办池，不插入当前阶段。
2. 只有出现以下情况才修改 V1 范围：评测数据显示原设计不成立、本人使用中发现核心流程有问题、或者实施时发现无法完成。修改时在对应文档写明原因和日期。
3. 不再为 V1 做新一轮开源框架横向选型。需要的库在 [02](./02-技术架构与数据模型.md) 中已指定；只有指定的库无法满足需求时才换。
