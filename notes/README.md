# 学习笔记

这里用于记录 agent-lab 的学习过程、实验结论和重构原因。

## 记录建议

建议每次实验至少记录：

1. 想验证的问题。
2. 手写实现的核心机制。
3. 实验过程和结果。
4. 推翻或保留当前方案的原因。
5. 是否适合迁移到正式项目 xinyu。

不要在笔记中记录真实 API Key、公司代码、内部接口、公司数据或其他敏感信息。

学习推进以“小而完整的闭环”为单位，逐步从读懂和复写过渡到独立分析、实现与调试。当前先共同拆解，每个主题留一个完整核心任务让学习者尝试，再按“概念 → 方向 → 局部示例 → 明确请求后的完整参考”逐级帮助；API 可以查，样板可交给 Codex。亲手输入不等于独立完成，功能验收与独立能力证据分开记录，保留真实源码、正确 RED、目标与全量回归及简短复述。
