# 学习笔记

这里用于记录 agent-lab 的学习过程、实验结论和重构原因。

## 记录建议

建议每次实验至少记录：

1. 想验证的问题。
2. 核心机制、设计理由与真实源码位置。
3. 实验过程和结果。
4. 推翻或保留当前方案的原因。
5. 是否适合迁移到正式项目 xinyu。

不要在笔记中记录真实 API Key、公司代码、内部接口、公司数据或其他敏感信息。

学习推进以“小而完整的闭环”为单位，当前以理解设计、读懂真实代码、判断与验证行为为主。Codex 可以提供完整局部参考及解释，不强制每个主题先独立手写、闭卷复现或变式练习；亲手输入、局部修改或委托实现按需要安排。保留真实源码核验、行为预测、新行为的正确 RED、目标与全量回归及简短复述，不把抄写量或测试通过直接当作掌握。

讲解与笔记优先回答四个问题：解决什么问题、为什么这样设计、代码怎样执行、如何证明有效。开源学习包含专门的产品体验、架构总览和设计对照，先建立整体认识，再沿核心源码深入，选取适合的设计改进自己的项目；不局限于临时查询当前问题。明确区分文档阅读、源码核验、实际体验、离线测试与生产经验，不将参考文章的功能清单直接扩成项目任务。

时间投入讲求有效，但不赶进度、不追求速成。实践与必要原理结合，允许充分讲解、追问和复习；最小闭环只控制范围，不压缩理解。复用已有代码、样板和验证，减少机械抄写与重复教程，不以从零手写整个系统为门槛。
