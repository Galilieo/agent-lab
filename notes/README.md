# 学习笔记

这里用于记录 agent-lab 的学习过程、实验结论和重构原因。

## 记录建议

建议每次实验至少记录：

1. 想验证的问题。
2. 手写实现的核心机制。
3. 实验过程和结果。
4. 推翻或保留当前方案的原因。
5. 是否适合迁移到正式项目 xinyu。

不要在笔记中记录真实 API Key、公司代码、内部接口、公司数据或其他敏感信息。
